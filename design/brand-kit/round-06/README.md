# NIVRA surveillance/security identity concepts

Three independent alternatives for selection. No identity approved.

1. Perimeter: crimson/graphite, interlocking structural N emblem.
2. Observation: sapphire/cyan, an open angular N emblem.
3. Readiness: orange/pine, a compact inset N emblem.

Each visual kit presents a primary lockup, one-color treatment, exact intended palette, supporting type direction, monitored-site notice, security workwear, control-room branding, responder phone and technical proposal cover. Editable written guidance, CSS variables and JSON palette/contrast data accompany each board.

The category is surveillance and security technology. SURVEILLANCE INTELLIGENCE is the proposed descriptor; Before impact. remains the product line. Color remains prominent without making the brand a cheerful campus campaign.

Every photo, screen, uniform and notice is generated concept artwork, not a real deployment or production interface. Cameras are generic existing infrastructure, not claimed NIVRA-manufactured hardware. Exact vector masters, small-size proofs, production templates, named/licensed font finalization and the final PDF guide follow selection.

See SECURITY-REFERENCES.md for the official-site category research and REVIEW.md for visual inspection notes. Intended colors are specified in tokens.json, not sampled from generated pixels.

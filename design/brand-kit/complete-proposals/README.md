# NIVRA brand-kit proposals

Three directions for review. No direction is selected or approved.

| Direction | Colours | Typeface |
| --- | --- | --- |
| 01 Insight | Electric blue, lime, ink, cool white | Manrope |
| 02 Assurance | Violet, apricot, aubergine, paper | Plus Jakarta Sans |
| 03 Vigil | Emerald, lemon, deep green, porcelain | DM Sans |

Each folder contains a six-page PDF guide, a visual identity board, exact CSS/JSON tokens, three licensed font weights with OFL terms, and editable SVG templates for a campaign poster, presentation cover and review card.

Open the PDF first. It covers identity, logo use, colour and typography, graphics and applications, voice and product language, and practical use. The SVG templates are draft application layouts with editable text and embedded fonts. PDF composition studies demonstrate the graphic system; they are not screenshots of the templates.

The standalone logo concepts are currently raster proposals. Final SVG/PNG symbol families, validated minimum sizes, exact lockups and print proofs follow direction selection. No final logo vector, trademark clearance or print-production approval is claimed.

Use the exact tokens and the guide's voice page as the source of truth. Generated board photography, credentials, screens, names and incidental slogans are illustrative. They are not deployment evidence or working software. NIVRA is the surveillance and response technology, not a camera manufacturer.

Font source records are in font-sources.json. Install the supplied fonts if an editor does not honour embedded SVG fonts. Application import behaviour outside the browser has not been tested.

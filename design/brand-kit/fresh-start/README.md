# NIVRA / new brand-kit directions

Start with NIVRA-new-brand-kit-directions.pdf: 12 pages, four per proposal.

- Keeper: an attentive guardian, vermilion/carbon/silver/white.
- Intercept: a mechanical intervention before contact, petrol/aqua/chalk/steel.
- Widefield: a broader field of observation, mulberry/persimmon/blush/onyx.

Each folder includes a full identity board, an editable campaign-banner.svg, exact CSS/JSON tokens and licensed fonts. SVGs contain editable text with embedded fonts. Board artwork was created with built-in Image Gen; native guide pages and banners were authored separately. PROMPTS.md records the independent initial prompts.

These are proposals. None is approved. Symbol artwork is raster concept art, not a final vector master. Native banners use plain NIVRA text and brand graphic fields. Final geometry, one-colour logo variants, small-size testing, trademark distinctiveness and print proofs remain unresolved.

Use the guide and tokens as the exact copy/type/colour specification. Incidental generated board slogans and UI details are illustrative. Photography is generated; neither it nor the UI is deployment evidence. No claim is made that NIVRA manufactures cameras.

Keeper colour rule: Carbon on Vermilion is 4.25:1 and is restricted to large text (at least 24 CSS px regular or 18.67 CSS px bold). For smaller text, use Carbon on White/Silver or White on Carbon. The white-on-orange button in the generated mockup is illustrative and is not an approved UI colour pairing. Brand colour alone never indicates an operational status.

Editable SVG layout import was verified in the browser only. Install bundled fonts if your design editor does not honour embedded fonts; font licences are included. The supplied fonts govern supporting type, not pixel-exact generated board lettering.

Verification: all 12 PDF pages rendered and visually inspected; all three SVG banners browser-rendered and inspected; nine specified small-text pairs exceed 4.5:1; PDF page count, SVG XML, font licences and ZIP integrity checked.

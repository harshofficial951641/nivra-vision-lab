# NIVRA / full-colour brand-kit concepts

Three complete identity proposals: Watchful (ember/aubergine), Peripheral (iris/celery), Lookout (evergreen/volt). Each folder contains a full visual board, usage guide, exact JSON/CSS palette tokens, type specifications and licensed fonts.

All three boards were visually inspected. Colour-token contrast pairs, image dimensions, font licence text and ZIP integrity were checked. Master logo vectors and final editable applications await selection. Generated text and colour pixels are illustrative; the native guides and tokens are authoritative.

The earlier isolated black logo explorations are not deliverables in this package. All preceding rounds remain rejected.

# NIVRA eye-based identity concepts

Harsh explicitly requested an eye direction and rejected crimson/graphite. These are three independent full visual kit concepts with new palettes. None is selected or approved for production yet.

1. N-Sight: an N formed inside the eye, indigo/sky.
2. Watchpoint: an open eye and offset focus point, emerald/citron.
3. Sightline: a horizontal split through the iris, amber/ink-violet.

Each folder contains the visual board, written concept guidelines, exact intended colors in JSON and CSS, and numerical contrast pairings. Boards show the mark in one color plus signage, security workwear, command-room context, responder software and proposal applications.

Eye symbolism is grounded in the user's direction and the surveillance product. The claim that NIVRA translates as sight was not substantiated and must not appear as fact. Source notes are in BRIEF.md.

Generated scenes are concept applications. No deployments or NIVRA-manufactured cameras are claimed. Raster lettering and pixel colors are approximate; exact SVG masters, consistent small details, licensed font finalization, transparent exports, application templates and a final PDF guide follow selection.

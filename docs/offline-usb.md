# Local camera setup

The main connection flow now uses a phone hotspot, without USB or cables.

Open **Start NIVRA.command** and follow [wireless camera setup](offline-wireless.md). The older **Start NIVRA USB.command** shortcut opens that same wireless setup, so there is only one onboarding flow.

The updated native iPhone app is required. The updated app was installed and launched wirelessly on Tanishq's iPhone. A real camera feed still needs verification; the local LAN source, native builds and automated tests have passed.
